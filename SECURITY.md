# Security and sensitive-data reports

Please do not open a public issue for leaked credentials, sensitive biometric
artifacts, or a vulnerability that could expose private data. Use GitHub's
private vulnerability reporting or security-advisory feature for this
repository instead.

For ordinary bugs, reproducibility problems, and documentation corrections,
open a public GitHub issue with the smallest non-sensitive example possible.

Never attach real-person images, face embeddings, access tokens, model-access
credentials, or private review files to an issue.
